# Reconhecimento de Voz com Python

Projeto simples de reconhecimento de voz que captura áudio do microfone e converte fala em texto usando a API do Google, configurado para português brasileiro (pt-BR).

## Funcionalidades

- Captura de áudio em tempo real pelo microfone
- Ajuste automático para ruído ambiente
- Reconhecimento de fala em português do Brasil
- Tratamento de erros comuns (timeout, áudio não entendido, falha de conexão)

## Pré-requisitos

- Python 3.6 ou superior
- Microfone funcionando no computador
